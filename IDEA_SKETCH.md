# Sketch BED3 course site

This is a rough outline of what this project will do.

## Goal

Build a course website for my undergraduate course in capital budgeting and finance at the Norwegian school of economics.

## Where we are now

Currently, I have a website hosted via github:
https://andresjuve.github.io/BED3/

I want to leverage AI to the fullest and create a new website serving the same purpose, which is: Motivate students to learn about capital budgeting and finance.

## Outline workflow

To achieve this, I was thinking that we should leverage google's Stitch: https://stitch.withgoogle.com/ to produce the design system etc., and then hand that off to you to actually build.

Before we start with google stitch, we need to pin down and identify the actual style and vibe of the site that we want. This should end in a prompt I can give to stitch. To build the relevant vocabulary, let's draw on the design language and styles as given by:

1. https://www.shillingtoneducation.com/blog/graphic-design-terms
2. https://www.kittl.com/blogs/design-styles-name-stl/
3. https://www.canva.com/learn/graphic-design-terms/
4. https://uxplanet.org/50-design-styles-every-designer-should-know-for-better-prompting-56c09d55db62

When the prompt is built, I'll do some iterations using Stitch, alternatively, we can connect you via an MCP and/or skills and do it like that.
